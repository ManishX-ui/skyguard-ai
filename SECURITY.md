# Security Policy

## Supported Versions

The following versions of SkyGuard AI currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The SkyGuard AI team takes security seriously. If you discover a security vulnerability or potential exposure within the repository, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to:
- `manish.kumarkashyap2025@ssipmt.com`

Please include:
1. Type of issue (e.g., credential exposure, denial of service, injection vulnerability)
2. Detailed steps to reproduce
3. Potential impact and affected components
4. Any proposed mitigation or patch

You will receive an initial response acknowledging receipt within 48 hours. We will collaborate with you to validate the vulnerability and release a patch prior to public disclosure.
